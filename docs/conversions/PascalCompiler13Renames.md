# Apple Pascal 1.3's Compiler: renames

The declarations the conversion renamed, for [PascalCompiler13.md](PascalCompiler13.md), each qualified by the
routines and records it is in. The names before are the private named source's, most of them UCSD Pascal II.0's
(PC3); a new name's doc gives the II.0 or Apple name a document has in `Also:` or in its remarks, so the names
before are kept only here. The 16 names the code file keeps (the program's and the segments') are not renamed.
