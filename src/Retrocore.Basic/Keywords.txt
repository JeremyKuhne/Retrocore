# BASIC reserved word help: word | dialects (a = AppleSoft, 2 = Level II, i = Integer BASIC, b = Business BASIC, c = Color BASIC) | syntax | what it does.
# Written for Retrocore from the interpreters' behavior; one line per word and dialect group.
END|a2b|END|Stops the program and returns to the prompt; CONT continues after it.
FOR|a2b|FOR v = start TO end [STEP increment]|Starts a loop: sets v to start, and NEXT adds the increment (1 by default) until v passes end. The body always runs at least once.
NEXT|a2b|NEXT [v [, v ...]]|Ends a FOR loop: adds the step and loops back while the variable has not passed the end.
DATA|a2|DATA item [, item ...]|Holds constants for READ. Items are numbers or strings; quotes are needed only around commas, colons or leading spaces.
INPUT|a2|INPUT ["prompt";] v [, v ...]|Reads values typed at the keyboard into variables, asking again when they do not fit.
DIM|a2b|DIM a(size [, size ...]) [, ...]|Makes arrays; each dimension runs from 0 to its size. An array used without DIM has 11 elements per dimension (0-10).
READ|a2|READ v [, v ...]|Takes the next items from DATA statements into variables.
LET|a2b|[LET] v = expression|Assigns a value; LET itself can be left out.
GOTO|a2b|GOTO line|Continues at a line.
RUN|a2|RUN [line]|Clears the variables and runs the program, from its first line or from the line given.
IF|a2|IF condition THEN statements|Runs the rest of the line when the condition is not zero; otherwise goes on with the next line.
RESTORE|a2b|RESTORE|Makes READ start again at the program's first DATA item.
GOSUB|a2b|GOSUB line|Calls the subroutine at a line; RETURN comes back to the statement after the GOSUB.
RETURN|a2b|RETURN|Returns from a GOSUB to the statement after it.
REM|a2b|REM text|A remark: the rest of the line is ignored.
STOP|a2|STOP|Stops the program with a BREAK message; CONT continues after it.
ON|a2|ON n GOTO line [, line ...] / ON n GOSUB line [, line ...]|Jumps to, or calls, the nth line of the list; goes on with the next statement when n is 0 or past the list.
WAIT|a|WAIT address, mask [, flip]|Waits until the byte at the address, exclusive-ored with flip and then anded with mask, is not zero.
LOAD|a|LOAD [name]|Loads a program from cassette, or under DOS from disk.
SAVE|a|SAVE [name]|Saves the program to cassette, or under DOS to disk.
DEF|a2b|DEF FN f(x) = expression|Defines a one-line function of one parameter, called as FN f(value).
POKE|a2|POKE address, value|Stores a byte in memory.
PRINT|a2|PRINT [items]|Prints numbers and strings: a semicolon keeps the cursor where it is, a comma moves to the next print zone, and no punctuation at the end starts a new line. ? is short for PRINT.
CONT|a2|CONT|Continues a program after STOP, END or BREAK, if it has not been changed.
LIST|a2|LIST [first] [- last]|Lists the program, or the lines given.
CLEAR|a|CLEAR|Clears every variable, array and string, and BASIC's stack.
GET|a|GET v|Waits for one key and puts it in a string variable, or its digit in a numeric one, without echoing it.
NEW|a2|NEW|Erases the program and its variables.
TAB(|a2b|TAB(column)|In PRINT: moves to a column.
TO|a2|FOR v = start TO end|Gives the end value of a FOR loop.
FN|a2b|FN f(value)|Calls a function DEF FN defined.
SPC(|ab|SPC(count)|In PRINT: prints that many spaces.
THEN|a2b|IF condition THEN statements / THEN line|Starts what IF runs when its condition holds; a line number alone jumps there.
AT|a|HLIN x1, x2 AT y / VLIN y1, y2 AT x / DRAW n AT x, y|Gives the row, column or position of a line or shape.
NOT|a2|NOT x|Logical not: 1 when x is 0, else 0 in AppleSoft; the bitwise complement of an integer in Level II.
STEP|a2b|FOR v = start TO end STEP increment|Gives a FOR loop's increment, which may be negative.
+|a2|a + b|Adds numbers, or joins strings.
-|a2|a - b, -a|Subtracts, or negates.
*|a2|a * b|Multiplies.
/|a2|a / b|Divides.
^|a|a ^ b|Raises a to the power b.
[|2|a [ b|Raises a to the power b; the key shows as an up arrow on the Model I.
AND|a2|a AND b|Logical and in AppleSoft (1 when both are not zero); bitwise and of integers in Level II, where true is -1.
OR|a2|a OR b|Logical or in AppleSoft; bitwise or of integers in Level II, where true is -1.
>|a2|a > b|Greater than: true when a is greater than b. Also part of >= and <>.
=|a2|a = b|Assigns in LET; compares elsewhere.
<|a2|a < b|Less than. Also part of <=, <> and =<.
SGN|a2|SGN(x)|-1, 0 or 1 as x is negative, zero or positive.
INT|a2|INT(x)|The greatest whole number not greater than x.
ABS|a2|ABS(x)|The absolute value of x.
USR|a|USR(x)|Calls the machine code that the JMP at $0A sends it to, with x in the floating-point accumulator, and returns what is left there.
FRE|a2|FRE(x)|The free memory in bytes. In AppleSoft it also compacts the strings first; in Level II, FRE of a string gives the free string space.
SCRN(|a|SCRN(x, y)|The color of a low-resolution graphics point.
PDL|a|PDL(n)|Reads game paddle n, 0-255.
POS|a2|POS(x)|The cursor's column; x is ignored.
SQR|a2|SQR(x)|The square root of x.
RND|a2|RND(x)|A random number. AppleSoft: between 0 and 1; a negative x seeds the sequence, and 0 repeats the last. Level II: RND(0) is between 0 and 1, and RND(n) is a whole number from 1 to n.

COS|a2|COS(x)|The cosine of an angle in radians.

VAL|a2|VAL(s$)|The number at the start of a string, or 0.
ASC|a2|ASC(s$)|The code of a string's first character.
CHR$|a2|CHR$(code)|A one-character string with that code.
LEFT$|a2|LEFT$(s$, n)|A string's first n characters.
RIGHT$|a2|RIGHT$(s$, n)|A string's last n characters.
MID$|a2|MID$(s$, start [, n])|Characters from a string, starting at position start (1 is the first).
