# The Z80's instruction-set description: what the assembler, disassembler and tools know about it.
#
# [isa] and [forms] describe the CPU (read by Retrocore.Isa.IsaParser). Each opcode line lists the opcode
# bytes, the instruction and its operand form, optionally 'undocumented', and 't=' with the nominal T-states
# (taken/not taken for a conditional instruction). A '*' among the bytes marks where the operand bytes go
# when the last opcode byte follows them, as after DD CB. A form the [forms] section does not declare is a
# literal form whose pattern is its name, such as A,[HL].
#
# The native syntax writes memory operands in brackets, [HL] and [nn], so parentheses always group an
# expression: LD A,(5+3) loads an immediate. An index displacement is written [IX+d], [IX-d] or [IX].

[isa]
endian little
address-bits 16
registers A:8 F:8 B:8 C:8 D:8 E:8 H:8 L:8 I:8 R:8 AF:16 BC:16 DE:16 HL:16 IX:16 IY:16 SP:16 PC:16 AF':16 BC':16 DE':16 HL':16
flags F S=7 Z=6 Y=5 H=4 X=3 P/V=2 N=1 C=0
# Documentation names flags by these words on every CPU, never by letter: Out: carry = found. The
# undocumented Y and X bits have none.
flag S negative "Set when a result's bit 7 is 1, a negative number in two's complement. Zilog calls it the sign flag."
flag Z zero "Set when a result is zero, or when a compare finds the values equal. BIT sets it when the tested bit is 0."
flag H half-carry "Set when a result carries out of bit 3 or borrows into it. DAA uses it to correct decimal results."
flag P/V parity|overflow "Overflow after signed arithmetic, set when the result passes -128 or 127; parity after logical operations, rotates and IN, set when the result has an even number of 1 bits. LD A,I and LD A,R copy IFF2 into it, and block transfers and searches set it while BC is not zero."
flag N subtract "Set by a subtract, cleared by an add. DAA uses it to correct decimal results."
flag C carry "Set when an add carries out of the top bit, or a subtract or compare borrows (A is less than the value). Shifts and rotates move bits through it."
literal-forms
entry-points 0000 0008 0010 0018 0020 0028 0030 0038 0066    # reset, the restarts and NMI
